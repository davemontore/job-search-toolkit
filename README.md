# Job Search Toolkit

AI tools for people leaving the military who already know what kind of job they want and have a master resume. They run in AI agent tools that can search the web and open pages: Claude Code, Claude Cowork, Codex, or ChatGPT with browsing.

## Start

Paste this into your AI tool:

```
Help me with my job search. Read and follow the Job Search Toolkit's START HERE file: https://raw.githubusercontent.com/davemontore/job-search-toolkit/main/START-HERE.md
```

It asks what you want to do and walks you through it. If your tool can save skills, it installs a small launcher first, so next time you can just say "Help me with my job search."

## The tools

Used in this order:

1. [Weekly Job Scan](tools/weekly-job-scan.md) finds live openings for a role, an experience range, and a set of locations.
2. [Resume Reforger](tools/resume-reforger.md) tailors your resume to one job posting, shows every change, and asks a few questions to make the bullets stronger.
3. [STAR Strategizer](tools/star-strategizer.md) prepares you for the behavioral interview. It works with the cut sheet [The Reusable Story](tools/the-reusable-story.pdf).

[Story Miner](tools/story-miner.md) is for people who feel they have no stories to tell. STAR Strategizer sends you there when you need it.

## Job scans

Weekly job scans, one folder per date, are in [scans](scans/README.md). Anyone can open them. Postings close fast, so check the scan date.

## Updates

The tools are read fresh from this repository every time they run, so everyone always has the current version.
